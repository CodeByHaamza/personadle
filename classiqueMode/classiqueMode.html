📋 Classic Mode Rules

🎯 Goal:
Guess the Persona character of the day using deduction and clues 🧩🕵️.

🧠 How it works:
  • 🔍 Each attempt shows how close your guess is to the correct character.
  • 📊 A grid compares multiple attributes like name, gender, age, arcana, etc.
  • 🟩 Green = correct, 🟨 Yellow = partial match, 🟥 Red = wrong.
📊 Criteria compared:
  • 👤 Name – Exact match required
  • ⚧️ Gender – Human, Shadow, Entity, etc.
  • 🎂 Age – Range (e.g. <15, 15–20, 40+)
  • 💥 Persona User / Shadow – Can they use a Persona or are they a Shadow?
  • 👺 Persona – The specific Persona or Shadow form
  • 🃏 Arcana – Their Tarot Arcana (Fool, Magician, etc.)
  • 🎮 Opus – Which Persona games they appear in
💡 Tips:
  • 🧠 Use deduction based on color-coded clues.
  • 📈 If the age isn’t exact, an arrow ↑ or ↓ appears.
  • 🟨 Yellow means partial match (e.g. some Arcana or one of several Opus).
♿ Accessibility:
  • 🌈 Daltonian Mode – A toggleable option replaces red/green/yellow with colorblind-friendly shades and adds symbols (✔, ▲, ✖) for better clarity.
🎮 Game flow:
  • ⌨️ Type a name and select from suggestions.
  • 🔁 You have 8 attempts max.
  • 💬 At 3 attempts: 🔓 Hint button unlocks (displays a quote).
  • ❌ At 8 attempts: 🔓 Give Up button unlocks (reveals the answer).
🛡️ Spoiler protection:

🕹️ Use the filter buttons (P1, P2, P3, P4, P5, P5X) to limit characters by game.
👀 This helps avoid spoilers if you haven’t played them all!

🎭 Think like a Phantom Thief... and unveil the truth!

🎯 Objectif :
Devinez le personnage Persona du jour grâce à la déduction et aux indices 🧩🕵️.

🧠 Comment ça marche :
  • Chaque tentative montre à quel point votre réponse se rapproche du personnage correct.
  • Une grille compare plusieurs attributs : jeu, genre, âge, arcane, etc.
  • 🟩 Vert = correct, 🟨 Jaune = correspondance partielle, 🟥 Rouge = faux.
📊 Critères comparés :
  • ⚧️ Genre – Humain, Shadow, Entité, etc.
  • 🎂 Âge – Tranche d’âge (ex : <15, 15–20, 40+)
  • 💥 Utilisateur de Persona / Shadow – Peut-il invoquer un Persona ou est-il un Shadow ?
  • 👺 Persona – Le Persona ou la forme Shadow spécifique
  • 🃏 Arcane – L’Arcane du Tarot (Fou, Magicien, etc.)
  • 🎮 Opus – Dans quel(s) jeu(x) Persona ce personnage apparaît
💡 Conseils :
  • 🧠 Utilisez la déduction grâce aux indices colorés.
  • 📈 Si l’âge n’est pas exact, une flèche ↑ ou ↓ apparaît.
  • 🟨 Le jaune signifie une correspondance partielle (ex : même série mais jeu différent).
♿ Accessibilité :
  • 🌈 Mode Daltonien – Remplace le rouge/vert/jaune par des teintes adaptées et ajoute des symboles (✔, ▲, ✖) pour plus de clarté.
🎮 Déroulement :
  • ⌨️ Tapez un nom et sélectionnez dans les suggestions.
  • 🔁 Vous avez 8 tentatives maximum.
  • 💬 À 3 tentatives : 🔓 L’indice se déverrouille (affiche une citation).
  • ❌ À 8 tentatives : 🔓 Abandonner se déverrouille (révèle la réponse).
🛡️ Protection anti-spoilers :

🕹️ Utilisez les filtres pour limiter les personnages par jeu.
👀 Cela évite les spoilers si vous n’avez pas encore joué à tous les jeux !

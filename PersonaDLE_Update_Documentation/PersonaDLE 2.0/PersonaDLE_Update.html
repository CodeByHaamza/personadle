Traduction i18n

5 langues (EN · FR · ES · DE · IT), 863 clés hiérarchiques. Détection auto de la langue navigateur au premier chargement, persistée en localStorage. Boutons de jeu traduits (images WebP par langue). Badges, valeurs de grille et attributs HTML traduits dans les 5 langues.

Détails techniques

Piège critique — t(key) ?? fallback ne fonctionne pas

t() retourne la clé brute (string truthy) quand la clé est absente — ?? ne se déclenche jamais. Pattern correct :

const r = window.i18n?.t?.(key);
return (r != null && r !== key) ? r : fallback;

Fix chemin depuis les sous-dossiers

L'ancien code construisait le chemin depuis window.location.href → 404 depuis les sous-dossiers. Fix : ancrage sur import.meta.url :

// js/i18n.js
var _langBase = new URL('../lang/', import.meta.url).href;

Offline-first — savePendingSession()

Fire-and-forget : tente l'API, sinon stocke en localStorage. Erreurs 409 → continue silencieux (session déjà connue).

export async function savePendingSession(session) {
  const api = window._personadleApi;
  if (api) {
    try {
      await api.stats.postSession(session);
      await api.stats.syncPending();
      return;
    } catch { /* réseau → fallback */ }
  }
  const q = JSON.parse(localStorage.getItem('pendingSessions') || '[]');
  q.push(session);
  localStorage.setItem('pendingSessions', JSON.stringify(q));
}

Fix _migrate() — expansion incorrecte

Un code n'est traité comme legacy que si aucun de ses sous-codes n'est déjà présent :

const children = LEGACY_EXPAND[code];
if (children) {
  const alreadyPrecise = children.some(c => saved.includes(c));
  if (alreadyPrecise) {
    if (allOpus.includes(code)) result.push(code);
  } else {
    result.push(...children.filter(c => allOpus.includes(c)));
  }
}

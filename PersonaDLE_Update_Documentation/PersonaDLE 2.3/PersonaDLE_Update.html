🃏 Data corrections

  • Elisabeth est désormais une utilisatrice de persona en mode Classique, avec Thanatos — qu'elle manie dans Persona 4 Arena Ultimax. Le mode Personae le savait déjà ; la grille du mode Classique disait le contraire. Theodore, lui, ne manie toujours aucune persona.

🔧 Corrections

🔧 Fixes

  • Paramètres — depuis votre profil, le bouton Sauvegarder se retrouvait sous le bas de la fenêtre : il reste maintenant affiché en permanence. Au passage, le panneau ne défilait plus du tout, ce qui rendait « Réinitialiser le profil » et « Supprimer mon compte » tout simplement inaccessibles sur les écrans peu hauts. Merci à Gypotre pour le signalement.
  • Mode Classique — un personnage de la tranche d'âge 60+ s'affichait en rouge au lieu de l'orange avec la flèche, même quand la réponse était plus âgée. Un seul personnage du jeu porte cette tranche, ce qui explique qu'elle soit passée inaperçue si longtemps.
  • Settings — from your profile, the Save button ended up below the bottom of the window; it now stays on screen at all times. Along the way, the panel had stopped scrolling entirely, which made "Reset Profile" and "Delete my account" simply unreachable on shorter screens. Thanks to Gypotre for the report.
  • Classic Mode — a character in the 60+ age bracket showed up red instead of orange with an arrow, even when the answer was older. Only one character in the game uses that bracket, which is why it went unnoticed for so long.
